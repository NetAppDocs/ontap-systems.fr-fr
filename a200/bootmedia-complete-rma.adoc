= Retournez le support de démarrage AFF A200 défaillant à NetApp
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Après avoir remplacé le support de démarrage défectueux AFF A200, retournez-le à NetApp conformément aux instructions de retour (RMA) fournies avec le kit. Consultez la  https://mysupport.netapp.com/site/info/rma["Retour de pièces et remplacements"] page pour plus d’informations.
