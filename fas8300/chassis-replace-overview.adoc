= Examinez les exigences avant de remplacer votre châssis FAS8300 ou FAS8700
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Avant de remplacer le châssis de votre système FAS8300 ou FAS8700, tous les autres composants du système doivent fonctionner correctement ; sinon, vous devez contacter le support technique. Cette procédure est prise en charge sur toutes les versions d'ONTAP, mais elle entraîne une interruption complète du service dans un cluster à deux contrôleurs et une interruption partielle dans un cluster à plusieurs nœuds.

* Cette procédure peut être utilisée avec toutes les versions de ONTAP prises en charge par votre système.
* Cette procédure est perturbatrice : un cluster à deux contrôleurs subit une interruption de service complète, et un cluster à plusieurs nœuds subit une interruption partielle.
