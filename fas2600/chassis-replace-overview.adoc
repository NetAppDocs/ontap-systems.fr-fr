= Vérifiez les exigences avant de remplacer le châssis d'un système FAS2600
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Avant de remplacer le châssis de votre système FAS2600, examinez les exigences relatives au déplacement des alimentations, des disques durs et du ou des modules de contrôleur du châssis défectueux vers le nouveau châssis, ainsi qu'au remplacement du châssis défectueux dans la baie d'équipement ou l'armoire système par le nouveau châssis du même modèle.

Tous les autres composants du système doivent fonctionner correctement. Dans le cas contraire, veuillez contacter le support technique.

* Cette procédure peut être utilisée avec toutes les versions de ONTAP prises en charge par votre système.
* Cette procédure est rédigée en supposant que vous déplacez tous les disques et modules de contrôleur vers le nouveau châssis, et que le châssis est un nouveau composant de NetApp.
* Cette procédure est perturbatrice. Pour un cluster à deux nœuds, vous avez une interruption de service complète, et pour un cluster à plusieurs nœuds, une interruption partielle.
