= Renvoyez le support de démarrage AFF C250 défaillant à NetApp après le processus de récupération de démarrage automatisé
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Après avoir remplacé le support de démarrage dans un système AFF C250, retournez la pièce défectueuse à NetApp, comme indiqué dans les instructions RMA fournies avec le kit. Consultez la page  https://mysupport.netapp.com/site/info/rma["Retour de pièces et remplacements"] pour plus d'informations.
