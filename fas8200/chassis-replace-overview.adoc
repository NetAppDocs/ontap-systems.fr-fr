= Examinez les exigences relatives au remplacement d'un châssis dans un système FAS8200
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Avant de remplacer le châssis dans un système FAS8200, vérifiez que tous les autres composants fonctionnent correctement et que le châssis de remplacement est un nouveau composant de NetApp du même modèle. La procédure nécessite de déplacer les alimentations, les ventilateurs et les modules de contrôleur vers le nouveau châssis et est perturbatrice, provoquant une interruption complète du service dans un cluster à deux contrôleurs ou une interruption partielle dans un cluster à plusieurs nœuds.

Tous les autres composants du système doivent fonctionner correctement. Dans le cas contraire, veuillez contacter le support technique.

* Cette procédure peut être utilisée avec toutes les versions de ONTAP prises en charge par votre système.
* Cette procédure est rédigée en supposant que vous déplaiez le ou les modules de contrôleur vers le nouveau châssis, et que le châssis est un nouveau composant de NetApp.
* Cette procédure est perturbatrice. Pour un cluster à deux contrôleurs, vous subissez une interruption de service complète et, dans un cluster à plusieurs nœuds, une interruption partielle.
