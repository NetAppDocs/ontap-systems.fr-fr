= Renvoyez le support de démarrage ASA A250 défaillant à NetApp après le processus de récupération de démarrage automatisé
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si un composant de votre système ASA A250 tombe en panne, retournez la pièce défectueuse à NetApp. Voir la page  https://mysupport.netapp.com/site/info/rma["Retour de pièces et remplacements"] pour plus d'informations.
