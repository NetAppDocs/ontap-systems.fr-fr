= Examinez les exigences avant de remplacer le châssis de votre système FAS2820
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour remplacer le châssis de votre FAS2820, transférez les alimentations, les disques durs et les modules de contrôleur du châssis défectueux vers le nouveau châssis. Ensuite, retirez le châssis défectueux de la baie ou de l'armoire système et installez le nouveau châssis du même modèle à sa place.

Tous les autres composants du système doivent fonctionner correctement. Dans le cas contraire, veuillez contacter le support technique.

* Cette procédure peut être utilisée avec toutes les versions de ONTAP prises en charge par votre système.
* Cette procédure est rédigée en supposant que vous déplacez tous les disques et modules de contrôleur vers le nouveau châssis, et que le châssis est un nouveau composant de NetApp.
* Cette procédure est perturbatrice. Pour un cluster à deux contrôleurs, cette procédure entraîne une interruption de service complète et, dans un cluster à plusieurs nœuds, une interruption partielle.
